# 快捷指令

两处入口共用本机配置：

- 多智能体输入框的 `+` 菜单 → 搜索与配置快捷指令。
- 设置 → 智能体 → 快捷指令（位于自动化下方）。

搜索面板提供全部、收藏、最近三种视图。点击星标收藏；选择现有指令后可以另存为自定义，也可以新建、编辑或删除本机指令。启动指令可保存 Agent、配置来源、工作目录、数量和任务正文。保存指令不会执行操作，也不会保存本次勾选的会话 ID。

## 范围与执行

每次执行前选择范围，再勾选具体会话：

| 范围 | 含义 |
| --- | --- |
| 当前工作区 | 主窗口当前工作区包含的 Agent 会话，按会话归属筛选，不按目录猜测 |
| 当前项目 | 当前选中会话所属项目的 Agent 会话 |
| 全部运行会话 | 所有可接收操作的 Agent 会话，包含空闲的原生聊天会话 |
| 选中会话 | 从可操作会话列表中手动选择 |

普通 Shell、归档会话、退役 Runtime 和运行命令的内部辅助会话不参与。删除动作允许选择已停止会话，范围标签相应显示“全部未归档 Agent 会话”。没有工作区或项目上下文的入口会禁用对应范围。

发送消息直接调用会话投递接口，正文提到项目时不会重新解释成项目任务。批量停止、删除需要第二次确认；确认期间变更选择会撤销旧确认。执行时再次核对目标身份，失败逐项显示，其他目标继续执行。

启动项根据本机已安装、已启用的 CLI 和已配置 Provider 生成。当前支持 Claude Code、Codex CLI、Kimi Code、Pi、OpenCode、ZCode CLI；默认沿用对应 CLI 的本地配置。Claude Code 可另选 CrewVela 中已配置凭据的 Provider。不会自动安装 CLI，也不绕过 CLI 自身的信任和权限检查。原生聊天会话可接收消息、停止和删除，本面板不提供新建原生聊天动作。

## 结果与存储

- 已启动：启动接口返回会话，不代表任务已执行。
- 已排队：消息进入发送队列，不代表已送达、已读或回复。
- 内容已写入：收到对应请求与目标的运输证据，不代表任务完成。
- 失败：显示该目标的实际错误；启动成功但排队失败时保留会话并说明情况。

自定义指令、收藏、最近和默认范围保存在应用本机存储 `crewvela-quick-commands-v1`，不写入 Git 仓库。指令中只记录 Provider ID，不复制凭据。存储损坏或写入失败时保留原数据并显示错误。
