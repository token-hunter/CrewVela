# 搜索快捷指令面板与设置入口

用户选择第 3 版搜索命令面板，并要求在设置的智能体分类中、自动化下方增加快捷指令配置入口。

## 实现

- 两处复用 QuickCommandCenter，支持搜索、收藏、最近、自定义指令与默认范围。
- 结构化动作：逐会话发送、启动本地 CLI、批量停止、从列表删除。
- 工作区与项目按真实会话归属筛选，原生聊天与 CLI 都可投递；执行前逐目标重新校验。
- 动态检测 Runtime 与 Provider 凭据是否配置，不读取或复制密钥值。
- 批量停止和删除二次确认；结果区分排队、文本写入、失败，不代称任务完成。
- 保留总控自然语言与项目协作入口；移除旧硬编码 MiniMax 快捷示例。自然语言解析得到广播、停止或删除时同样转入目标核对。
