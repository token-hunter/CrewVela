# 侧栏额度摘要改为当前工作区待处理入口

Status: ready-for-human

## 需求与实现

- 用户已选择按需显示待处理的方案。无事项时只保留设置按钮；有事项时汇总待授权、执行失败数量。
- 输入范围沿用主界面当前工作区的会话集合，不受侧栏搜索、类型和状态筛选影响。归档、退役及已恢复的会话不提醒。
- 复用现有会话状态刷新，不增加 IPC、账户读取、定时器或应用焦点查询。删除旧 Codex 摘要组件、专属样式和已无入口的首页账户弹窗；其他模块仍使用的账户后端保留。
- PTY 仅在等待原因明确指向授权时提示；原生聊天管理器的 Waiting 对应工具授权，其原因可能仅为工具标题，不能依赖授权关键词。
- 授权项进入现有会话核对，失败项打开只读错误与历史。点击前重新核对当前状态，失效授权也走只读记录；不会因查看失败自动恢复进程。
- 支持忽略本次失败并本地持久化。只保存会话 ID、类型与事件时间，不保存错误文本、目录或任务内容；保存失败时明确提示且保留提醒。
