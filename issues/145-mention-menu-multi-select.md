# @成员候选框支持多选

Status: ready-for-agent
Execution: completed

## 需求与范围

在现有 @候选弹窗中连续勾选多个具体成员，保留快捷单选及全选，不改变成员能力、权限或后端路由。

## 实现

- 新增多选开关、勾选状态、插入所选按钮；单选模式仍点击即插入，多选模式保持弹窗打开直至确认。
- 使用成员身份保存临时选择，过滤后保留勾选，确认时核对当前可用成员；关闭或切换项目清空临时状态。
- 批量插入保留前后正文、换行、光标位置，不重复已有完整 @成员；未确认多选不发送，也不生成分工。
- 支持方向键移动、Space 勾选、Enter/Tab 插入、Esc 取消。过滤无结果时仍可确认先前选择或取消。
- 修正候选行样式作用域，使既有样式实际作用于当前群聊中的勾选控件。
