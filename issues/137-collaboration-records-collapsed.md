# 协作记录默认全部收起

用户明确要求取消首条记录自动展开；只有点击某条记录才展开/收起，其他记录不受影响，刷新与筛选不能自动打开记录。

根因是 CollaborationRecordsPanel 初始化 expanded 时加入了首条记录 ID。采用空集合初始化，保留已有独立切换与项目/标签页重建行为。规格及证据位于 `.scratch/collaboration-records-collapsed/spec.md`。

## 验证

- 修复前正式组件浏览器断言失败：`all records must be collapsed on entry`，实际展开 1 条、期望 0 条。
- 移除初始化首条记录逻辑后，同一回归通过。覆盖首次/重新进入、逐条独立展开收起、键盘、刷新新增首条不展开、已手动选择保持、搜索与类型筛选不展开、项目切换默认收起。
- 既有完整正文、搜索、记录类型、投递错误重试、项目异步隔离、工作台宽度回归通过；记录投影单元测试 3 项通过；类型检查和生产构建通过（既有大包警告保留）。
- 实际打开检查 `collapsed.png`，所有箭头朝下且没有详情块。浏览器使用正式 React 组件和隔离 IPC；未操作生产数据，未做新 EXE 原生窗口验收，未提交或打包。
