# Beta 的 MCP 接入范围

设置中的通用 MCP 管理页面和快捷入口已移除，不再提供任意服务器的新增、编辑、删除、开关及集中连接检测。

底层 MCP 接入继续保留：浏览器控制由对应设置维护内置服务；共享记忆继续使用自己的安装、配置与接入检查；协作内部服务和 Codex 原会话通信服务保持原有通道。

旧 `mcp-servers.json` 的服务器、参数和启用状态继续读取，已有工具仍按各 Runtime 原有支持范围注入。此次移除不删除旧注册表，也不修改用户本地 Agent CLI 的 MCP 配置。原本的传输类型限制保持不变。

旧侧栏快捷入口配置中的 MCP 项会被过滤，其余选择保留。旧页面定位回退常规设置。

验证分别记录配置读取/注入、协议及界面回归。真实模型工具调用、记忆捕获检索和 Agent 双向实收回复不能由 Mock、连接成功或排队成功替代；此前暂缓的 Claude/Codex 真实互聊继续列为待验收。
