# 首次启动即展示会话通信提示

## 需求

用户要求新用户首次打开软件就知道 Agent 可以互相通信，不再等待两个 Agent 启动；关闭后不重复弹出。

## 验收

- 零会话、侧栏展开或收起时，首次启动均能看到一份轻提示。
- 关闭提示或查看教程后持久化已读；重开、刷新及切换工作区不重复提示。
- 复用既有已读键，已关闭旧提示的用户不被重新打扰。
- 进入多智能体项目不重复展示提示，教程仍按当前项目打开。
- 常驻入口、示例筛选、诊断和复制行为保持可用。
