# ai-memory 官方稳定版发现与托管更新

Status: ready-for-human

## 需求与边界

不再把 2.6.0 写死为安装默认版本，跟随官方稳定发布；提供检查更新和显式更新，兼容 Windows/macOS 一键安装，保护记忆及接入配置。用户未要求本轮提交、推送、更新 Release 或升级真实服务。

## 实现

- 由官方 GitHub Releases API 发现稳定版及对应平台包，核对固定官方 URL、大小、SHA256；工作任务冻结版本，后端重新解析官方目标 tag。
- 按数值比较版本；适配 2.6+ 的 2.x/3.x，未来大版本先阻止安装；缺包、缺摘要、网络或限流失败明确显示。已有兼容安装可离线继续接入，不因检查失败强制升级。
- 增加当前/最新版本、安装更新和跨大版本确认。只更新 CrewVela 托管路径，保留外部安装管理权；不自动重启 Agent 会话。
- 更新前检查候选程序的必要命令能力，再停止持有句柄的服务并保存完整冷快照。迁移后验证版本、健康、MCP 工具与项目作用域；失败恢复原安装/数据/配置，保留候选写入。外部并发配置不覆盖；中断记录阻止继续启动，提供确认恢复入口。
- OS 文件锁阻止多个 CrewVela 实例重叠进行托管操作；不根据 PID 文件终止外部服务。
- v3 新目录认证与本地 token 文件接入，令牌不发给其他端点或前端 IPC；命令输出中的完整令牌及截断边界令牌片段脱敏。保留 Codex v3 对破坏性工具的 prompt 审批配置，自定义覆盖仍停止自动接入。
- 文档记录认证、备份范围、失败恢复、联网校验需求及 Mac 原生验收步骤。

## 实际验证（Windows 主机，2026-11-11）

- 共享记忆 Rust：50 通过、6 默认 opt-in；其中 4 项真实发行包测试额外显式运行通过：官方最新稳定版在线下载/校验/安装（约 43 秒）、3.4.5 全新启用/重复配置、2.6→3.4.5 真实迁移/故障回退/重试、两种 Mac 3.4.5 包摘要/生产提取器验收。两项本机真实服务 opt-in 检查未运行。测试未操作真实用户记忆或 Agent 配置。
- 恢复测试验证旧程序、旧数据、接入配置、失败候选写入保留；并发外部配置不覆盖且保留恢复记录。其他回归覆盖工具审批、版本范围、恶意/缺失元数据、令牌输出、进程句柄及监听边界。
- 隔离命令守卫 Rust 8 项通过，新增恢复命令在新用户隔离模式被拒绝。
- Node 444 通过、1 项既有跳过；TypeScript/Vite 构建通过。
- 向导、原设置、接入修复三套 Chrome 检查通过；覆盖 Windows/Mac 包型、更新请求版本、跨大版本确认、外部安装、GitHub 离线、未适配大版本、失败后恢复入口、深浅色/600px、进度恢复及卸载清理。已查看更新界面真实浏览器截图；IPC 为模拟。
- 原有 Rust 20 条警告和前端分块体积提示保留，没有降低检查或新增扫描忽略规则。
- 候选源码独立复制扫描未命中密钥；包含忽略目录的宽扫描另有 3 条发现：隔离 `init` 自动生成的 `token_pepper`，以及 `dist` 中两条依赖压缩枚举 `FourKeyMap`。前者仅为本次临时数据，后两者为压缩代码误报；均未进入候选源码，未新增忽略规则或修改检测器。
