## 已确认的问题与修复

| 问题 | 修复及验证方式 |
| --- | --- |
| Agent 或外部编辑器修改文件后，保存旧草稿会覆盖新内容 | 保存请求携带读取基线；后端写临时文件前和替换前均检查，冲突时保留磁盘内容和界面草稿；Rust 与浏览器回归先失败后通过 |
| 目录链接循环或多个别名造成重复搜索、漏搜及文件树重复 key | 文件树保留可见入口路径；搜索按 canonical 目录和结果目标去重，继续校验工作区边界；Windows junction 循环回归 |
| 创建、删除、归档、改名等会话操作写盘失败后，内存已被改变 | 四类创建及十一类管理操作先持久化候选数据，再发布内存；删除成功后才清理辅助状态；只读文件故障注入验证失败与重试 |
| 修改已有模型服务 ID 实际创建了另一条配置，还共用原密钥 | 既有 ID 只读，保存固定原 ID 与密钥引用；新建继续生成独立标识；验证失败重试与新建行为 |
| 删除共享密钥的服务会破坏其他服务，内置拒删也先触碰凭据 | 先拒绝内置删除；有其他引用时保留凭据；独占密钥删除后的写盘失败执行回滚并如实报告回滚失败；使用注入凭据接口验证，不访问真实 keychain |
| 模型服务配置替换出现路径空窗，后台读取可能写默认配置 | 同目录单次原子替换，初始化、迁移及读改写共享模块存储锁；发布前真实读取、并发读写及发布失败保留旧文件的回归先失败后通过；独立复核确认无重入锁 |
| 中文输入法确认/取消候选触发模型选择或关闭弹窗 | Modal、ModelCombobox 忽略组合输入及 keyCode 229；验证草稿保留、普通选择和两级 Escape |
| 900px 及最小窗口左栏仍占空间却隐藏会话导航 | 统一侧栏显式保持会话区域，继续使用已有收起控制；实际验证 820×540 至 1920×1080、明暗主题及缩放 |
| 浅色主题沿用亮色强调背景，白色按钮文字对比不足 | 为八种强调色提供浅色主题色值，设置导航沿用当前强调色；实测 16 组主题组合的主按钮及悬停状态对比度均达到 4.5:1 |
| 浏览器预览调用原生事件接口产生未捕获异常，原生监听失败缺少提示 | 预览不注册原生监听；原生失败显示错误；取消监听与组件生命周期同步，浏览器面板订阅使用最新回调且不反复注册 |
| Windows HTTP 测试夹具间歇出现 WouldBlock，完整回归失败 | 共享记忆健康探测、ZCode 分页和 MCP HTTP 夹具的 accepted socket 显式恢复阻塞，分段请求读取完整头部；超时专用夹具用 channel 管理生命周期；保持真实 20ms 超时断言、MCP body/会话/SSE 检查和生产时间预算 |

## 验收边界

- 浏览器 UI 使用项目已有 preview/隔离 IPC fixture；证明前端显示和交互，不代表真实账户、模型服务或原生 WebView2 端到端验收。
- 本轮不调用付费模型、不修改用户真实模型凭据；没有重新执行真实多 Runtime 通信。macOS/Linux 原生构建与真机验收未执行。
- Node 的一项 POSIX shell 测试在 Windows 跳过，文件符号链接检查另因 Windows 权限不足打印跳过提示；目录 junction 循环回归实际执行通过。Unix 文件权限新增回归未在 Windows 执行。
- 外部编辑器不参与本应用互斥锁，仍存在最后一次内容比较与文件替换之间极窄的外部写入窗口；未宣称实现跨进程原子 compare-and-swap。
- 会话管理操作现在保证失败不发布候选状态；已实际发生的进程退出、审批消费等不可逆运行事实保留原有语义，不盲目回滚。
- 构建保留前端大 chunk 提示和 Rust 既有警告，没有关闭警告阈值或隐藏警告。
