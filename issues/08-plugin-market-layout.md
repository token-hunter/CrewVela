# 修复打开插件市场时的尺寸跳变

## 目标

直接操作 Windows 原生应用确认点击插件市场后的变化，修复可复现的尺寸跳变，保留当前窗口状态和已有页面功能。

## 验收

- 设置分类切换时，共用导航、标题、纵向留白保持稳定。
- 插件市场搜索、分类、详情和相邻设置页面可正常使用。
- 验证普通窗口、最小支持尺寸和宽屏布局，明暗主题无水平溢出。
- 区分原生外框变化与设置内容变化，不以浏览器测试代替原生验收。
