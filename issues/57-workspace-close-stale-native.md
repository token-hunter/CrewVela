# 修复遗留原生聊天记录阻止关闭工作区

## 范围

- 复现关闭工作区时多种原生聊天报“会话不存在”的错误。
- 修复失败启动遗留总会话记录、Runtime 尚无内部记录时的停止/删除路径。
- 保留进程身份、停止失败、未持久化消息、工作目录和交接保护；不通过前端吞掉错误放行。
- 测试仅使用临时目录，不读写用户真实历史；不提交、推送或更新 Release。

## 验收

- 经实际 delete_session_inner 入口删除五类 ACP 与 Pi 的无定位记录会话。
- 有消息记录的正常停止仍标记中断；真实持久化和进程停止失败仍返回错误并保留会话。
- 工作区正常关闭、部分失败保留、新会话竞态及会话选择回归。

## 根因与实际结果

- 经实际 `delete_session_inner` 入口复现：DeepSeek/Claude/Kimi/Codex/OpenCode 原生聊天及 Pi 都在停止阶段更新不存在的历史时失败，与截图文案一致。
- ACP 和 Pi 的历史中断收尾对缺失记录改为无操作；仍执行原有安全停止、回复刷盘与原子保存。没有吞掉前端错误，也未修改工作目录/交接保护。
- 复现测试先失败、修复后通过，覆盖六类遗留记录，并核对其他会话及其历史字节不变。
- Rust 针对性 32 项通过（停止流程30、实际删除入口1、删除回滚1）；前端工作区/批量操作8项通过；差异检查通过。Rust 既有警告保留。
- 新增测试确认正常流式消息会保留并改为中断；历史写入失败仍报错，缺定位且有未持久化回复时保留缓冲和原会话。
- 测试仅操作临时目录和模拟进程，未改动真实历史。未跑全量 Rust、未重打 EXE、未实机点击验收；未提交、推送或更新 Release，当前运行中的旧 EXE 尚不包含修复。
