# CrewVela v0.1.0

把 Claude Code、Codex 等编程 Agent 放进同一桌面工作台，进行会话通信、项目协作与工作交接。

## 下载

- **Windows x64**：`CrewVela-0.1.0-windows-x64-setup.exe`，NSIS 安装向导，简体中文 / English，当前用户安装。
- **SHA256SUMS.txt**：核对实际上传文件的完整性，不代替签名。
- **macOS Apple Silicon（ARM64）**：`CrewVela_0.1.0_macos_aarch64.dmg`，约 23 MiB，附同名 `.sha256` 校验文件。使用 ad-hoc 签名，未做 Developer ID 签名或公证。

需要本机 Node/npm、对应 Agent CLI 及账号。Windows 缺少 WebView2 时，安装向导会联网下载引导程序。安装包不包含全部 Agent 或模型；正常模式会使用本机配置，升级无需清空个人历史。

## macOS Apple Silicon 更新

2026-11-10，`CrewVela_0.1.0_macos_aarch64.dmg` 已基于合入 `main` 的应用源码提交 [`2651ded`](https://github.com/token-hunter/CrewVela/commit/2651ded63832e17787d83e66f728e11124997eda) 在 Apple Silicon Mac 上重新构建，替换此前 `66df105` 构建。包名和下载链接保持不变，独立 `.sha256` 与 `SHA256SUMS.txt` 已同步更新；Windows 附件及其校验值保持不变。

- 修复此前剩余的 13 项 Rust 回归失败：8 项属于平台夹具或路径断言，另 5 项涉及 ZCode shim 解析、权限 deny 路径别名、资源包路径校验及 PTY 退出清理竞态；扩大验证时额外修复 ZCode 编辑测试夹具发布 CAS 版本的顺序。
- macOS 权限 deny 规则覆盖符号链接与临时目录别名，避免通信目录权限被意外放宽；资源包路径检查拒绝 Windows 风格的父目录和绝对路径。
- Darwin 已退出但未回收首领仍保留进程组身份；仅在身份核实后清理原组成员。退出过渡只允许在原有时限内等待，不降低进程身份和活动成员检查。
- 保留此前关闭工作区、协作中心直接创建项目、统一设置窗口及按 Runtime 管理 Skill 的更新。
- 本轮 macOS Rust 全量：库 1028 通过、bin 1 通过，共 1029 通过、0 失败；37 项原有 opt-in 测试未运行。未新增忽略或删除有效检查。
- 本轮 Node 回归：433 通过、5 项原有跳过、0 失败。PTY reader 清理问题用例连续通过 20 次；ZCode 编辑用例连续通过 50 次。
- 本轮 ARM64 发布构建、生产资源集成检查 1/1、DMG 完整性、包内严格签名与构建路径隐私检查通过；保留已有编译警告。
- Windows 专属生产执行逻辑保持原实现；本轮未执行 Windows 实机或 Windows CI 验证，不宣称 Windows 动态回归已通过。
- 本轮没有 UI 修改。此前设置、项目、成员流程和 Skill 功能/滚轮布局回归记录保留；Skill 键盘到末尾滚动断言在 macOS Chrome 未通过，未在本轮修复。
- 原生 macOS 界面完整交互、系统目录选择器、安装副本正常退出、真实 Agent/模型工作流未完成验收。ad-hoc 签名，未做 Developer ID 签名或 Apple 公证。

## English

CrewVela brings coding agents into one desktop workspace for messaging, collaboration, and handoffs. The unsigned Windows x64 installer remains built from commit 66df105. The Apple Silicon ARM64 DMG has been rebuilt from commit 2651ded with the Rust cross-platform regression and PTY cleanup fixes. macOS Rust tests passed (1029 passed, 37 existing opt-in tests not run); Node tests passed (433 passed, 5 existing skips). The DMG uses ad-hoc signing and is not notarized. Package and embedded resource checks passed. Windows runtime regression, full native macOS interaction and real agent/model workflows remain unverified. The previous macOS Chrome Skill keyboard end-of-list scrolling failure is still unresolved. Node/npm, agent CLIs, and accounts are required. See the linked records for setup and verification limits.
