# 修复多智能体面板唤起 Claude 与 Codex 后的通信

## 需求与现象

用户通过右侧面板 @ClaudeCode @Codex 请求互相打招呼。Codex落在C:\Windows并出现命令执行环境错误，Claude未收到指令，Codex还向自身排队发送。

## 验收

- Windows扩展路径启动经过CMD的CLI后仍在指定项目目录。
- 其他桌面实例不能消费不属于自己的启动事件；新版同一数据目录只能有一个桌面实例。
- 每位参与者收到明确的自身身份及其他接收者，优先使用绑定身份的会话MCP；不向自己发送。
- 定向发送继续只派发给发送方；人类发送及会话间通信、权限和消息持久化不回归。
- 通过回归测试及隔离真实CLI验收，不终止用户当前会话，不将排队描述为送达。
