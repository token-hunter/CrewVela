# 群聊复制消息

用户授权：用户消息和 Agent 回复的右下方增加复制按钮，悬停提示“复制消息”。只复制该条完整正文，保留换行/代码，成功后显示“已复制”，不带姓名、状态和其它消息。

复用现有 Tauri 剪贴板插件及已有写权限。空回复占位和内部计划卡片不是正文，不提供复制隐藏数据的入口。失败可见且能重试，流式正文变化后不显示旧内容的成功反馈。

规格与验证：`.scratch/conversation-message-copy/spec.md`。本轮不提交、不打包。
