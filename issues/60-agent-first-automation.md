# 自动化按 Agent 配置并默认沿用本地模型

## 已确认方案
用户选择第一版单页表单：基本信息 → 执行 Agent → 执行任务 → 触发与运行；高级模型和护栏折叠，底部显示摘要和保存按钮。

## 实施
- 新增显式 Runtime 动作、目标身份校验、事件来源过滤、重叠策略和可持久化的目标跟踪。
- 独立 CLI 复用既有启动器，Provider 凭据继续从原凭据库读取；模型覆盖只存会话，不写 CLI 全局配置。
- 项目成员复用调度桥，已有交互 PTY 保留。队列结果与真实任务完成分开表达。
- 旧 v2 配置兼容，原有日历、cron、最大次数、熔断行为保留。

## 验收边界
浏览器隔离夹具与 Rust/Node 测试验证；未使用用户真实账号运行自动化任务，未在 macOS 原生客户端实测。未提交、推送或打包。

## Comments
测试结果与实际界面证据见本地 design-qa.md 和 .scratch/automation-agent-first/evidence/；原型选型后直接实施，未改动其他工作树的快捷指令等在途修改。
