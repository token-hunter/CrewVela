# 生成包含当前未提交功能的干净开源副本

- 目标目录：`.`，仅在不存在或为空时生成，避免覆盖其他内容。
- 导出当前工作区的已跟踪文件和未忽略新增文件，保留未提交功能；不使用仅包含 HEAD 的 archive。
- 排除原 Git 历史、环境凭据、账号/会话数据、缓存、依赖、构建物和本地备份，保留 `.env.example`。
- 核对源文件与副本 SHA-256，重新扫描密钥、凭据及个人邮箱，检查公开文件清单。
- 建立全新的空 Git 仓库用于验证忽略规则，不配置远程、不提交、不推送。
- 在副本上运行适当验证，清除仅为验证产生的依赖链接及构建物，交付本地审计记录。
