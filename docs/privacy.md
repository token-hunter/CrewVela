# CrewVela 隐私政策

说明更新：2026-11-16。本说明描述当前 CrewVela 应用的数据处理范围。你接入的 Agent CLI、模型服务、记忆服务与工具有各自的数据处理方式。

## 本机应用记录

CrewVela 会在应用数据目录与本机界面存储中保存运行所需的设置、会话索引、工作区状态、协作消息、任务和执行记录。根据使用的会话类型，记录还可能包含提示词、回复、工具输出、目录与运行错误。上下文和用量展示也可能在本机保存结构化状态信息。

## Agent、模型与工具

CrewVela 使用你本机安装或配置的 Agent CLI。任务内容、项目上下文及工具请求会按实际调用和所选成员范围交给相应 Agent 或服务处理。模型请求是否发送至远程服务、服务如何保留或使用内容，取决于该 CLI、模型服务和工具的配置与政策；CrewVela 没有统一控制这些服务模型训练或数据保留行为的开关。

浏览器控制、Skills 与其他接入工具可能访问网页、项目文件或外部服务。请核对这些工具和 Agent 的权限及信任范围。共享记忆由当前配置的记忆服务保存，应用记录、CLI 原生历史与记忆服务数据需要分别管理。

## 登录与凭据

本地 Agent 的登录状态和原生配置由对应 CLI 管理。CrewVela 自身管理的部分凭据使用系统凭据库；这不代表所有第三方登录文件、日志和会话内容都经过 CrewVela 加密。请勿在任务、截图、公开 Issue 或反馈中粘贴密码、Token 或不需要分享的私人内容。

## 自动与手动检查应用更新

应用启动后、运行期间定时以及你点击“检查更新”时，CrewVela 会向 GitHub 请求此仓库的公开发行信息。请求包含来源 IP 和带应用版本的 User-Agent 等常规 HTTP 信息。检查和下载均不发送会话内容、CLI 登录凭据或共享记忆。在支持应用内更新的版本中，点击“更新”后才开始下载和校验安装包。点击发布页链接会在浏览器打开 GitHub。

## 管理与删除

你可以通过会话、归档会话、协作中心、共享记忆和浏览器控制中的现有入口管理对应数据与访问。不同记录与服务的删除范围不同，删除应用中的一条记录不等于同时清除所有 CLI 历史、项目产物或外部服务数据。当前没有覆盖所有这些数据的统一导出或一键清除接口。

## 开源、反馈与变更

公开源码不等于公开你机器上的应用数据。但你主动上传的日志、截图、项目文件与发行附件可能包含私人信息，分享前请自行检查。安全问题请查看仓库 SECURITY.md 的说明，不要在公开反馈中暴露凭据。后续功能或服务接入发生变化时，本说明也会相应更新。
