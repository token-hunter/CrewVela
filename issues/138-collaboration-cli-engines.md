# 多智能体统一 CLI 执行引擎

用户选择七个新成员引擎：Claude Code、Codex、Kimi Code、Pi、OpenCode、ZCode CLI、DeepSeek Harness（dsh）。独立 Chat 不改，DeepSeek 保留聊天界面并通过 dsh 执行。ZCode Desktop 不再新增或作为切换目标；已有成员、账号/模型、任务与记录保留原路径兼容，不静默映射。

规格与证据：`.scratch/collaboration-cli-engines/spec.md`。只修改成员准入、协作目录及对应验证；不修改生产数据、权限或登录配置，不提交或打包。

## 实施结果

- 新成员/切换目录统一为七个 CLI；DeepSeek 沿用 dsh ACP。会话展示仍保留 6 个终端、7 个 Chat，独立 Chat 与全局安装/登录映射不删除、不重分类。
- 后端创建、更新和协调器计划均校验新成员准入；接口不能绕过页面新建 Desktop 或五种独立 Chat。无效切换在停止旧会话前拒绝。
- 旧 ZCode Desktop 成员显示兼容选项，可保留原 Runtime、角色、模型、权限及任务关系。角色编辑不再清空已有模型。只有用户主动选择 CLI 并保存才切换，界面明确目标 CLI 登录/默认模型语义，旧记录保留。
- 新项目群聊仅报告七引擎；有旧 Desktop 成员的项目额外报告兼容能力。旧调度/恢复名单和执行路径保留，未自动禁用或映射旧成员。
