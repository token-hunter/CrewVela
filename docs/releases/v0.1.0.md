# CrewVela v0.1.0

把 Claude Code、Codex 等编程 Agent 放进同一桌面工作台，进行会话通信、项目协作与工作交接。

## 下载

- **Windows x64**：`CrewVela-0.1.0-windows-x64-setup.exe`，NSIS 安装向导，简体中文 / English，当前用户安装。
- **SHA256SUMS.txt**：核对实际上传文件的完整性，不代替签名。
- **macOS Apple Silicon（ARM64）**：`CrewVela_0.1.0_macos_aarch64.dmg`，约 23 MiB，附同名 `.sha256` 校验文件。使用 ad-hoc 签名，未做 Developer ID 签名或公证。

需要本机 Node/npm、对应 Agent CLI 及账号。Windows 缺少 WebView2 时，安装向导会联网下载引导程序。安装包不包含全部 Agent 或模型；正常模式会使用本机配置，升级无需清空个人历史。

## English

CrewVela brings coding agents into one desktop workspace for messaging, collaboration, and handoffs. The unsigned Windows x64 installer is rebuilt from application commit 421bd67 with session/project pinning, the task-first collaboration layout, single-column browser settings and the local Claude Code configuration entry. It retains the CrewVela installer logo. Node tests passed (442 passed, 1 existing skip); seven isolated Chrome UI suites, one targeted Rust contract test and the embedded resource check passed. The unchanged macOS DMG does not include these four additions. The Apple Silicon ARM64 DMG has been rebuilt from commit 2651ded with the Rust cross-platform regression and PTY cleanup fixes. macOS Rust tests passed (1029 passed, 37 existing opt-in tests not run); Node tests passed (433 passed, 5 existing skips). The DMG uses ad-hoc signing and is not notarized. Package and embedded resource checks passed. Windows runtime regression, full native macOS interaction and real agent/model workflows remain unverified. The previous macOS Chrome Skill keyboard end-of-list scrolling failure is still unresolved. Node/npm, agent CLIs, and accounts are required. See the linked records for setup and verification limits.
