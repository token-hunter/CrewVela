# 共享记忆服务更新与项目接入分离

## 需求

服务更新不要求重选项目或 Agent，沿用已有接入配置；保留跨大版本确认、完整数据备份与失败恢复。首次安装与项目接入单独执行，并验证受影响流程。

- 已在浏览器隔离测试复现：无项目和 CLI 时，即使确认跨版本，原更新按钮仍禁用。
