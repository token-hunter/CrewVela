# CrewVela v0.1.0

把 Claude Code、Codex 等编程 Agent 放进同一桌面工作台，进行会话通信、项目协作与工作交接。

## 下载

- **Windows x64**：`CrewVela-0.1.0-windows-x64-setup.exe`，NSIS 安装向导，简体中文 / English，当前用户安装。
- **SHA256SUMS.txt**：核对实际上传文件的完整性，不代替签名。
- **macOS Apple Silicon（ARM64）**：`CrewVela_0.1.0_macos_aarch64.dmg`，约 23 MiB，附同名 `.sha256` 校验文件。使用 ad-hoc 签名，未做 Developer ID 签名或公证。

需要本机 Node/npm、对应 Agent CLI 及账号。Windows 缺少 WebView2 时，安装向导会联网下载引导程序。安装包不包含全部 Agent 或模型；正常模式会使用本机配置，升级无需清空个人历史。

The Windows x64 installer is rebuilt from application commit `b6e9525`, based on the latest main branch. It includes the Codex Chat npx startup fix for paths with spaces or shell metacharacters and the browser MCP entry-point fix for junction/symlink compatibility directories, together with the existing UI and workflow updates. The v0.1.0 tag and automatic source archives include these fixes and the latest documentation; only release notes were added after the application build.

Node tests passed (444 passed, 1 existing skip), as did 28 ACP and 14 browser-control Rust regression tests. The real Codex npx adapter initialized with an isolated CODEX_HOME without a model request. A real browser MCP handshake through an isolated junction discovered 25 tools without opening a browser. Production embedded resources, installer icons and personal build-path checks passed. Full Rust, installation/upgrade/uninstallation and real model workflows were not verified. The installer is unsigned.

The macOS ARM64 DMG and its checksum attachment remain unchanged, based on commit `2651ded`. They do not include this Windows update. It uses ad-hoc signing and is not notarized. Existing macOS verification limits above still apply. Node/npm, agent CLIs, and accounts are required.
