# 项目质量审查与 Hermes Agents 移除

状态：本轮审查、修复与本机可执行验证完成。分支：`quality-hermes-removal-audit`。在原有大量未提交改动基础上继续，未回滚、提交或推送。

## 本轮变更

- 移除 Hermes 的前端选项、运行时身份、协作成员/模板、技能/插件分发支持、后端适配器、探测升级、消息桥、标题/历史适配、会话交接及专用脚本、图标和专用测试。
- 未知历史运行时统一作为不可执行的 `unsupported` 处理；保留历史，不替换成其他 Agent 执行。新增生产代码残留扫描及不可选回归。
- 修复 Codex 账户面板本地存储异常：读取失败不使面板崩溃；成功切换或重启后，提醒保存失败单独显示，不误报实际操作失败。
- 修复协作中心、新建菜单、Agent 选择与原生标签中 Pi/OpenCode 默认图标在暗色背景上难以辨认的问题；自定义成员头像不反色。预览成员名称与实际运行时、角色对齐。
- 退役历史会话隐藏无效恢复按钮，说明记录已保留；未知运行时仍可选中查看会话信息，但不会启动进程。
- 修复经典五段 cron 的星期编号、日/星期 OR 语义，以及显式未来年份漏掉较早月份的问题；六/七段保留既有编号与组合语义。旧文件一次迁移至 v2：保留合法到期点，纠正错误星期，重排未来点；不追补旧版遗漏的历史任务，也不改禁用、限次耗尽或非 cron 任务。
- 原生回合结果与连接状态分离：ACP、Pi、ZCode 在真实回合结束点产生完成/失败事件，取消不算成功/失败；常驻 tick 在无 PTY 时也处理事件。重复回合去重，恢复旧历史不重放完成事件；Pi 模型错误/持久化失败不得触发成功。
- 未知历史运行时容错读取与新协调器计划校验分离，拒绝未知运行时的新计划。
- 共享记忆健康测试的 HTTP fixture 改为完整读取请求头，避免单次读取导致提前关闭连接；生产错误分类和原断言保持不变，定向连续 8/8 通过。

## 验证边界

浏览器 Mock IPC 不等于原生 Tauri、真实登录账户或模型服务的端到端验收。本轮没有启动真实模型任务、变更用户登录态或执行账户重启。

macOS/Linux 原生构建与实机、真实外部工具/账户/模型服务仍需对应环境验证。已有研究文档可能描述历史第三方产品，不代表当前仍支持执行。删除当前源码不清除 Git 历史。

原生回合终态按 turn ID 去重；随后发生的独立连接断开仍属于失败事件。协议没有提供同因标识，不跨不同 tick 强行合并模型失败与后续断连。

本报告不作“所有环境绝对无 Bug”的承诺；交付依据为实际修复、测试结果及明确边界。
