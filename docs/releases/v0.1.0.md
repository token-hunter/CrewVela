# CrewVela v0.1.0

把 Claude Code、Codex 等编程 Agent 放进同一桌面工作台，进行会话通信、项目协作与工作交接。

## 下载

- **Windows x64**：`CrewVela-0.1.0-windows-x64-setup.exe`，NSIS 安装向导，简体中文 / English，当前用户安装。
- **SHA256SUMS.txt**：核对实际上传文件的完整性，不代替签名。
- **macOS Apple Silicon**：可从源码构建；新 DMG 待原生重新构建和复核，当前不提供旧包。

需要本机 Node/npm、对应 Agent CLI 及账号。Windows 缺少 WebView2 时，安装向导会联网下载引导程序。安装包不包含全部 Agent 或模型；正常模式会使用本机配置，升级无需清空个人历史。

## 本轮改进与验证

- 清理文档、预览及截图中的个人路径和历史任务文字；发行构建映射编译路径、移除调试信息。
- 安装形态从运行时目录发现依赖；Codex 本地安装与 npx 回退复用固定版本包装桥。
- npm 全量与生产依赖审计零告警；Node 433 项通过、1 项既有跳过，相关 Rust 回归及资源检查通过。
- Windows 使用 `npm run tauri -- build --no-bundle` 构建，随后生成 NSIS；安装包解出程序的空数据启动与正常退出通过。
- 当前源码及 Windows 安装器、解包资源的扫描未发现真实密钥或构建个人路径。扫描不保证识别所有格式的秘密。

附件对应本仓库 `v0.1.0` 标签，后续源码更新不会自动替换附件。原仓库历史和旧包保留在独立私有备份中，没有带入本仓库。

## 验证边界

- Windows 安装包未做 Authenticode 签名；完整安装、升级、卸载、干净机器及真实模型工作流仍待验收。
- Rust 依赖漏洞审计未完成；npm 零告警不等于没有未知漏洞。
- Mac 新包、安装副本正常退出、真实 Agent/模型等仍需 Mac 原生验证；不提供已验证的 Intel Mac / Linux 包。
- 独立首次启动测试模式禁用真实 Agent、账号和共享记忆操作，不用于完整业务验收。
