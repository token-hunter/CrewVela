# 精选插件目录

插件市场采用左侧分组目录、右侧详情与安装面板。搜索、类别、适用 Agent、可安装筛选可组合；“已安装”可查看不在当前精选中的历史插件，“待接入”可查看当前目录中需授权或尚未适配的条目。

## 维护内置候选

`src/data/curated-plugins.json` 是原生后端和界面预览共用的内置清单。

- `sources`：声明来源 ID、仓库地址、作者和完整固定提交。
- `plugins`：声明名称、中文标题、用途、分类、来源 ID、仓库子目录、使用依赖和许可说明。
- 安装按条目引用的来源、固定提交和子目录解析，不再在内置安装分支硬编码单一来源。
- 本轮从 6 项增加为 16 项，均来自 Anthropic Skills 的同一固定提交。新增候选不代表依赖已安装、在所有 Agent/操作系统执行成功，或源代码统一采用同一许可；安装时保留上游文件并按其许可与说明使用。

新增条目需先核实上游存在有效 `SKILL.md`、内容可独立分发、来源和版本明确、依赖与许可可说明；安装时仍使用已有兼容性检查，含 MCP/连接器或原生宿主引用的包不得冒充独立 Skill。

## 精选与安装分别管理

新增候选不会覆盖用户已保存的精选或空名单，也不会自动下载或安装。已有用户可通过「管理精选」加入新增条目；目录为空或未选满内置候选时会提示当前内置候选数。

安装继续要求明确目标、作用域与来源信任确认。原生 Claude/Codex 插件通过对应 CLI 安装整包，不拆分或转换为其他格式；Skill 分发不同时启用 MCP、Hooks 或子 Agent。安装失败保留选择以便重试。

## 验证

- Rust `plugin_market` 回归覆盖清单与固定来源、精选持久化、安装隔离、兼容性和原生适配。
- `pluginMarket.test.mjs` 校验目录过滤和来源链接。
- `pluginBrowser.ui.mjs` 覆盖双栏选择、键盘、筛选后信任重置、无结果时移除旧安装按钮、待授权、已安装和加载重试。
- `pluginMarket.ui.mjs`、`pluginCuration.ui.mjs`、`pluginMarketOfficial.ui.mjs`、`pluginAsync.ui.mjs` 覆盖安装/移除契约与故障恢复。

浏览器使用正式 React 组件和隔离 Mock IPC；不等于新增 Skill 在真实 Agent 中的任务执行验收。EXE、DMG 和 macOS 真机需要另外构建验证。
