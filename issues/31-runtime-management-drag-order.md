# 管理 Runtime 支持鼠标上下拖拽排序

## 验收

- 鼠标拖动行或左侧把手，在同组目标行上/下半区插入并自动保存。
- 保留上下按钮、启用开关、禁用项排序、刷新后持久化及协作中心同步。
- 禁止跨组、外部拖放和自身拖放；取消/拖出后清理反馈，不意外切换启用状态。
- 验证实际鼠标拖拽、相关回归与构建，按指定命令打包。

## 实现与验证

- 行和左侧拖动柄均可拖动；根据目标行上/下半区插入，沿用已有排序保存和错误提示。
- 同时处理 dragenter 与 dragover，避免快速垂直经过图标、文字等子元素后松开时浏览器拒绝投递。
- 保留 ↑ / ↓、启用开关与组内限制；拖动结束后抑制意外点击，不切换启用状态。
- Chrome 隔离页面用真实鼠标验证：上下拖动、禁用项移动、整行拖动、CLI/聊天跨组拒绝、原有箭头、关闭重开及刷新保留顺序；开关调用数始终为 0。使用专用存储键，没有改动用户实际排序。
- 全量 Node 测试 413 通过、1 跳过；新增拖拽回归覆盖上下插入、拒绝外部/自身/跨组拖放及取消清理。
- 隔离页面及截图：`.scratch/runtime-management-drag-order/`。未在原生打包 WebView 内复测鼠标拖拽，待人工验收。
- 已执行 `npm run tauri -- build --no-bundle`：类型检查、前端生产构建和 Windows release 构建通过，输出 `src-tauri/target/release/CrewVela.exe`；构建仍报告已有 Rust 警告和 bundle identifier 提示。
