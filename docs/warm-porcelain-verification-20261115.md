# 暖瓷白替换极光：实施与验证

按用户选择的第 1 版，新增暖瓷白的完整表面、文字、边框、悬停和终端配色，替换原极光。界面顺序为深色、深海、暮紫、浅色、暖沙、暖瓷白，形成上排三深、下排三浅。

沿用历史 `aurora` 配置标识，将其浅色基类修正为 light，已有极光配置无需清理或重建；其他背景、强调色、透明度和跟随系统配置保留。未新增皮肤或恢复已删除入口。普通浅色设置窗口的白色覆盖规则对暖瓷白豁免，侧栏沿用暖灰白层次；跟随系统提示复用基类解析，正确标示浅色。
